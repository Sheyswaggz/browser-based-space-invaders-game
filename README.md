Classic arcade Space Invaders game built with vanilla JavaScript and HTML5 Canvas. Experience nostalgic gameplay with modern web technologies, featuring responsive design and smooth 60 FPS performance.

## Features

- 🎮 **Classic Gameplay** - Authentic Space Invaders arcade experience
- 📱 **Responsive Design** - Adapts seamlessly to desktop and mobile devices
- ⚡ **60 FPS Performance** - Smooth animations using requestAnimationFrame
- 🎯 **Mobile Support** - Touch controls for mobile gameplay
- 🏗️ **Modular Architecture** - Clean ES6 module structure for maintainability
- 🧪 **Comprehensive Testing** - 90%+ code coverage with Jest
- 🚀 **Continuous Deployment** - Automated deployment to GitHub Pages

## Tech Stack

- **HTML5** - Semantic markup and Canvas API for rendering
- **CSS3** - Modern styling with Grid and Flexbox layouts
- **JavaScript (ES6+)** - Vanilla JavaScript with ES6 modules
- **Canvas API** - Hardware-accelerated 2D graphics rendering
- **Jest** - Testing framework with jsdom for DOM testing
- **ESLint** - Code quality and security linting
- **Prettier** - Consistent code formatting
- **GitHub Actions** - CI/CD pipeline automation
